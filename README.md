# 잠잠 (JamJam) — 아기 수면의식 가이드

생후 12주(3개월) 이하 아기를 재우는 부모를 위한 실시간 의사결정 지원 웹앱 MVP.
수면의식은 언제 시작해도 좋으며(Mindell 2015), 밤낮 리듬이 생기는 생후 6주
무렵부터 효과를 체감하기 쉽다.
어두운 침실에서 우는 아기를 안고 한 손으로 조작하는 상황을 전제로,
화면에는 항상 "지금 할 일 하나"만 보여주고 부모는 판단 없이 버튼만 누른다.

## 사용법

- **실행**: `index.html` 더블클릭해 브라우저로 열기 (파일 하나가 전부)
- **배포**: GitHub Pages 등 정적 호스팅에 업로드 시 그대로 동작
- **의존성**: 서버·빌드 과정 없음, 외부 라이브러리 없음
- **네트워크**: 런타임 요청 0회 (오프라인 동작, 데이터는 기기에만 저장)
- **권장 환경**: 모바일 세로 화면, 한 손 조작

## 핵심 기능

- **상태머신 기반 가이드**: [수면의식 순서도](./docs/sleep-routine-flowchart.md)를
  상태머신으로 1:1 구현 (준비 5단계 → 눕히기 → 관찰 → 위험신호 → 원인 체크
  (배고픔이 1번) → 트림 재시도(수유 후 30분 이내만) → 진정계단 7칸 →
  교대/응급). 배고픔 신호가 보이면 진정계단 어느 칸에서든 수유로 탈출 가능
- **타이머 자동 집계**: 마지막 수유 후 경과 / 누적 강성울음(교대 기준 30분) /
  연속 울음(병원 기준 2시간)을 별도로 집계. 연속 울음은 소강 시 즉시 정지,
  5분 내 재개하면 이어서 집계, 5분 이상 잠잠하면 초기화. 2시간 도달 시
  어느 화면에서든 응급 안내로 자동 전환. 타임스탬프 기반이라 화면 잠금·
  백그라운드에서도 정확
- **세션 복구**: 모든 상태 전이를 localStorage에 저장. 새로고침·브라우저 종료
  후에도 타이머 값까지 복구
- **근거 각주**: 모든 가이드 화면 하단에 의학 자료·전문가 가이드 출처 표기
  (대한소아청소년과학회, NHS 영국 국민보건서비스, NICE 영국 국립보건임상
  연구원, Seattle Children's 미국 시애틀 아동병원, AAP 미국소아과학회
  (HealthyChildren), KidsHealth, MedlinePlus 미국 국립의학도서관,
  UNICEF Baby Friendly, Tresillian·Raising Children Network 호주 정부 지원
  기관, Harvey Karp 미국 소아과 전문의, Kaiser Permanente)
- **전역 안전 버튼**: 어느 화면에서든 [위험신호 확인]·[부모 한계]·[처음부터]
  접근 가능. 의식 없음·무호흡·청색증 시 119 안내 최우선 표시. 체온은
  촉진(만져보기) 1차 → 해당 시에만 측정 2차의 2단계 스크리닝
  (발열 38.0°C↑ / 저체온 36.0°C↓)

## 면책

이 앱은 의료 조언이 아니며 보호자의 판단을 대체하지 않는다.
응급 상황에서는 즉시 119에 연락할 것.
