# 잠잠 (JamJam) — 아기 수면의식 가이드

생후 4~12주 아기를 재우는 부모를 위한 실시간 의사결정 지원 웹앱 MVP.
어두운 침실에서 우는 아기를 안고 한 손으로 조작하는 상황을 전제로,
화면에는 항상 "지금 할 일 하나"만 보여주고 부모는 판단 없이 버튼만 누른다.

## 사용법

`index.html` 파일 하나가 전부다. 더블클릭해 브라우저로 열거나, GitHub Pages 등
정적 호스팅에 올리면 그대로 동작한다. 서버·빌드·외부 의존성 없음, 런타임
네트워크 요청 0회.

## 핵심 기능

- **상태머신 기반 가이드**: 수면의식 순서도 v1.3을 상태머신으로 1:1 구현
  (준비 5단계 → 눕히기 → 관찰 → 위험신호 → 원인 체크 → 트림 재시도(수유 후
  30분 이내만) → 배고픔 게이트 → 진정계단 7칸 → 교대/응급)
- **타이머 자동 집계**: 마지막 수유 후 경과 / 누적 강성울음(교대 기준 30분) /
  연속 울음(병원 기준 2시간)을 별도로 집계. 타임스탬프 기반이라 화면 잠금·
  백그라운드에서도 정확
- **세션 복구**: 모든 상태 전이를 localStorage에 저장. 새로고침·브라우저 종료
  후에도 타이머 값까지 복구
- **근거 각주**: 모든 가이드 화면 하단에 의학 자료·전문가 가이드 출처 표기
  (NHS, Seattle Children's, KidsHealth, MedlinePlus, Harvey Karp,
  Kaiser Permanente, 똑게육아)
- **전역 안전 버튼**: 어느 화면에서든 [위험신호 확인]과 [부모 한계] 접근 가능.
  의식 없음·무호흡·청색증 시 119 안내 최우선 표시

## 면책

이 앱은 의료 조언이 아니며 보호자의 판단을 대체하지 않는다.
응급 상황에서는 즉시 119에 연락할 것.
